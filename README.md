# VK MIX

Музыкальный плеер для Windows · **by Den4iK**

## Скачать

**[Последняя версия VK MIX](https://github.com/Den4iKKing/VK-MIX/releases/latest)**

- `VK-MIX-…-setup-x64.exe` - обычный установщик, рекомендуемый вариант.
- `VK-MIX-…-portable-x64.exe` - запуск без установки.

Windows 10/11 x64 и интернет для музыки ВКонтакте. Дополнительные компоненты устанавливать не требуется. При первом запуске нажмите «Войти через ВКонтакте» и подключите свой аккаунт через официальную форму с QR-кодом или другим способом входа. Затем нажмите Play: плеер сам запустит музыку из вашей коллекции или рекомендаций. При следующем запуске сохранённый вход восстановится автоматически.

## Возможности

В версии **0.7.0 Pulse** полностью обновлён интерфейс: верхняя навигация, крупные объёмные значки, подсвеченные кнопки и карточки. Библиотека, плейлисты, настройки и миниплеер получили общее оформление с адаптацией к размеру окна и масштабу.

- Музыка и плейлисты ВК, персональные подборки, поиск и локальные аудиофайлы.
- Медиаклавиши Windows, фоновое воспроизведение и трей.
- Компактный миниплеер, масштаб интерфейса, прозрачность и закрепление окна.
- Эквалайзер, очередь, избранное и таймер сна.
- Интеграции с OBS, Streamlabs, Stream Deck и Mirabox.
- Уведомление о новой версии, загрузка и установка по кнопке в приложении.

## Как обновляться

Начиная с 0.6.0, при появлении нового релиза плеер показывает «Доступно обновление». Нажмите «Скачать обновление», затем «Установить и перезапустить». Музыка не прерывается до нажатия установки. Профиль и настройки сохраняются.

Для версии 0.5.2 или старше один раз запустите новый установщик поверх старой программы. В portable-версии скачайте новый EXE, закройте плеер и замените прежний файл.

Сборки пока без цифровой подписи издателя, Windows может показать предупреждение. Приложение развивается; доступность конкретных треков зависит от ВК и аккаунта.

В репозитории находятся только описание и дистрибутивы приложения. Исходники хранятся отдельно и не публикуются здесь. Сообщить об ошибке можно в [Issues](https://github.com/Den4iKKing/VK-MIX/issues), указав версию приложения, Windows и шаги воспроизведения.
